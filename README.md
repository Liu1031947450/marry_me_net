# 四季小径 · A Stroll Through the Seasons

一个送给喜欢的人的像素农场求婚小游戏。玩法参考 Nicky Case 的 [it's a(door)able](https://ncase.me/door/)：亲手移动小人，收集钥匙，走进下一扇门，最后回放曾经走过的路。

这里保留需求中的 **四个独立房间 + LOVE**，不是原作的三个房间与 I ♥ U。画面采用原创 Canvas 像素场景，不使用《星露谷物语》的游戏素材或音乐。

## 本地运行

需要 Node.js 22.12+。

```sh
npm install
npm run dev
```

终端会显示访问地址。同一局域网的手机可以访问终端显示的 Network 地址。

```sh
npm test
npm run build
npm run preview
```

纯前端项目，无需 API、账号、数据库或环境变量。构建结果在 `dist/`，可以部署到任意静态网站托管服务。

## 在线游玩与部署

游玩地址：[四季小径](https://liu1031947450.github.io/formygirl/)。分享这个链接即可直接游玩，无需登录 GitHub。

仓库使用 GitHub Pages，部署来源为 **GitHub Actions**。推送到 `main` 后，`.github/workflows/deploy.yml` 自动安装依赖、运行测试、构建并发布 `dist/`；也可以在仓库 Actions 页面手动运行 **Deploy to GitHub Pages**。构建资源使用相对路径，支持项目子目录访问。

## 玩法

1. 页面先显示四季探索开始菜单，点击“开始游戏”进入春日花园并自动播放背景音乐。标题、图标、任务和过关文案不提前提示告白或求婚。
2. 用方向键 / WASD 在道路范围内自由移动，可随时转向、后退和组合按键斜走。斜向不会加速，不能穿过草地或路边。镜头随真实位置移动，只显示附近道路，不提前展示完整字母。
3. 手机单指拖动固定摇杆，支持 360° 自由转向；轻推慢走，推满达到原来的最高速度，松手立即停止。中心 15% 为停止区，拖出底座仍可控制，其他手指不会抢占方向。摇杆按住时优先于键盘和方向按钮，不叠加速度；桌面仍可使用原有方向按钮。不需要点击选路，也没有空格自动前进或自动返回。
4. 每个房间有 **5 条可试走的岔路（共 20 条）**，与通向出口的小径使用相同样式。直接按方向走进岔路即可，不需要切换路线或点击按钮。
5. 岔路尽头分别是倒木、石堆、栅栏或断桥，角色不能穿过去。沿原路自行返回；走错不会丢失钥匙或增加主路进度。主路和岔路都能自由往返。
6. 接近金色钥匙自动拾取，实际走过的主路区段去重计入探索进度。主路探索达到 100% 且取得钥匙后花门才会打开，抵达门口进入下一章；闭环可以反向走，但不能拿到钥匙后折返直接跳过剩余道路。
7. 依次走过四季，主路和岔路分段记录真实坐标，转入岔路不会留下虚假连线。第四个房间完成后回放真实走位，岔路足迹淡出，保留实际走过的主路并组合成 LOVE，不补画未走过的路线。
8. 随后自动出现“你愿意嫁给我吗”。“愿意”先展示原有成功结局，保留 LOVE、像素情侣、纪念日期和彩纸；点击“看看我们的照片墙”可浏览照片，随时“返回结尾”。“不愿意”会在安全区域内俏皮地躲开，不遮挡“愿意”或离开屏幕。
9. 可以选择“我想再走走”返回游戏，不会被强制选择。重新开始前需要确认。

没有计时或失败惩罚。玩法说明与重新开始弹窗会暂停移动，失焦、切换页面、过关、重新开始或屏幕尺寸变化都会清空输入，恢复后需要重新操作。松开按键即停止对应方向；摇杆松手、触摸取消或指针捕获丢失时立即回中并停止摇杆输入。进度仅保存在本次页面会话，刷新会重新开始。

## 单屏布局

页面按浏览器可用高度布局，不需要滚动。大标题、装饰卡和页脚已精简，顶部保留音乐、三步玩法说明及重新开始；较小屏幕将四季进度移到顶部。触屏设备通过 `pointer: coarse` 启用摇杆，竖屏放在画布下方右侧，短横屏放在右侧控制栏并隐藏冗余操作提示，两种朝向均靠右对齐，便于右手操作。底座为 112px，短横屏缩为 96px，摇柄保持 48px，不遮挡地图。游戏、过关弹窗、轨迹回放、求婚和成功页均采用单屏布局。

完整展示的验收下限是正常缩放的 `320×568` 竖屏和 `667×375` 横屏；浏览器工具栏与安全区变化会重新分配画布空间。小于此范围的极小窗口不保证完整展示。

照片墙沿用奶油白、鼠尾草绿和暖粉色，使用 `public/img/` 中的 7 张爱心占位插画，不包含个人照片或 EXIF 信息，以软木公告板、微倾斜错落照片、半透明纸胶带和相纸阴影呈现手工粘贴效果。桌面三列、平板两列、手机单列，仅照片区域内部滚动，不改变游戏的单屏布局。点击“开始游戏”后，全部照片以低优先级在后台预加载，利用游玩时间提前准备浏览器缓存；不阻塞开局，下载失败也不影响游戏。仅停留开始菜单或查看说明不会提前下载照片。照片墙保留按原始比例展示、懒加载和键盘放大预览，优先复用已加载图片；尚未完成的图片仍继续正常加载。按 Escape 或“回到照片墙”关闭预览。新增或替换照片时，同步修改 `src/PhotoWall.tsx` 中的照片清单、描述及尺寸；公开上传前请确认图片不含个人隐私，并移除 EXIF 信息。

## 音乐与可访问性

- 点击开始菜单的“开始游戏”时自动开启音乐，支持鼠标、触屏和键盘激活。仅打开页面、按移动键或查看说明不会进入游戏或播放音乐。
- 右上角可随时开关音乐；手动关闭后，继续移动、切换房间或重新开始都不会自动取消静音。Web Audio 实时生成原创轻音乐、脚步和提示音，不加载外部音频。
- 音频不可用时仍可完成全部游戏，页面会显示提示。
- 支持键盘、触屏、焦点样式、状态播报、弹窗焦点管理和系统“减少动态效果”设置。移动端的方向按钮保留在无障碍树中，键盘聚焦时显示，可替代拖动摇杆操作。
- “不愿意”支持鼠标、触屏及键盘触发；减少动态效果时取消位移动画。

开始菜单与音乐交互回归：启动开发服务后，已安装 Ego Browser 的环境可运行以下命令，检查开始按钮、键盘与触屏激活、静音保留、音频失败重试和九种单屏尺寸。第二个参数也可替换成在线游玩地址。

```sh
ego-browser nodejs -e "
const { verifyStartMenu } = await import('file://$PWD/tests/audio.browser.js');
const task = await taskSpace('开始菜单与音乐回归');
console.log({ taskSpaceId: task.spaceId });
await verifyStartMenu(task.page('p1'), 'http://localhost:5173/');
await task.finish({ keep: [] });
"
```

结尾与照片墙回归（仅开发服务）：将上方导入改为 `tests/photos.browser.js` 的 `verifyPhotoWall`，并调用 `await verifyPhotoWall(task.page('p1'), 'http://localhost:5173/')`。检查开局后 7 张照片预加载、到达结尾前可离线复用图片缓存、四季通关、点击“愿意”后保留成功结尾、照片墙往返、图片展示、键盘预览、重新开始及九种横竖屏尺寸。

摇杆回归：将上方导入改为 `tests/joystick.browser.js` 的 `verifyJoystick`，并调用 `await verifyJoystick(task.page('p1'), 'http://localhost:5173/')`。使用真实触摸事件模拟，检查力度与转向、拖出底座、松手与取消、多指、暂停恢复、通关换房、旋转屏幕、无障碍方向按钮及四种手机横竖屏尺寸，并回归桌面键盘和鼠标按钮。`npm test` 同时覆盖停止区、向量限速、非法输入及键盘／模拟向量各自的四季与 20 条岔路通关。

## 修改内容

- `src/game.ts`：道路碰撞、键盘／模拟向量移动、摇杆停止区与力度、主路覆盖进度、钥匙与出口条件、分段轨迹和按钮移动边界。
- `src/scenery.ts`：原创像素地图、角色、钥匙和花门绘制。
- `src/GameBoard.tsx`：游戏帧循环、键盘与触屏输入、暂停及状态提示。
- `src/Ending.tsx`：轨迹回放、求婚和成功结局。
- `src/PhotoWall.tsx`：照片墙、返回结尾与照片预览。
- `src/audio.ts`：背景旋律和游戏音效。
- `src/styles.css`：响应式页面与动画。

所有按钮、卡片、标签、进度条、弹窗和功能图标都使用真正的 `animal-island-ui` 组件。场景、像素角色和装饰画由项目自行绘制。
