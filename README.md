# 四季小径 · A Stroll Through the Seasons

一个可以送给喜欢的人的像素风求婚小游戏。穿过春夏秋冬，把走过的路变成告白，再用照片墙收藏属于你们的回忆。

基于 React、TypeScript 和 Canvas，纯前端运行，无需账号、数据库或后端服务。

## 游戏简介

- **四季探索**：依次穿过四个房间，探索小径、收集钥匙，完成探索后进入下一关。
- **简单操作**：电脑使用方向键 / WASD，手机使用虚拟摇杆；没有倒计时或失败惩罚。
- **惊喜结尾**：通关后，走过的路线组成 LOVE，进入求婚画面。
- **回忆照片墙**：点击“愿意”后，可查看照片墙、放大照片、返回结尾；支持自定义照片和配文。
- **氛围陪伴**：像素场景、背景音乐与音效，适配电脑和手机。

## 本地运行

需要 Node.js 22.12 或更高版本。

```sh
git clone https://github.com/Liu1031947450/marry_me_net.git
cd marry_me_net
npm ci
npm run dev
```

打开终端显示的地址即可游玩。发布时运行 `npm run build`，将生成的 `dist/` 部署到静态网站托管服务。

## 重点：替换结尾照片墙

**仓库默认提供 7 张爱心占位插画，不含个人照片。换成自己的照片和配文，就能制作专属版本。**

### 1. 放入自己的照片

图片存放在 `public/img/`。最简单的方式是用自己的 JPG 照片覆盖 `memory-01.jpg` 至 `memory-07.jpg`；也可以使用其他文件名或 PNG、WebP 格式，并在下一步同步修改清单。不要只修改后缀来转换图片格式。

### 2. 修改照片清单与配文

打开 `src/PhotoWall.tsx`，修改顶部的 `photos` 数组，每个对象对应一张照片：

```tsx
{
  file: 'memory-01.jpg',
  caption: '第一次一起看海',
  alt: '两个人站在海边的合照',
  width: 1080,
  height: 1440,
},
```

- `file`：图片文件名，大小写和后缀必须一致，**不用加 `public/img/` 前缀**。
- `caption`：照片下方的配文，也是放大预览的标题。
- `alt`：图片内容描述，方便屏幕阅读器识别。
- `width`、`height`：新照片的实际像素宽高，**覆盖同名图片后也要同步更新**，不必裁成原图尺寸。

照片按数组顺序展示。新增照片就添加一个对象，减少照片就删除对应对象，调整顺序就移动对象；数量不必固定为 7 张。**不再使用的图片也要从 `public/img/` 删除**，仅删除清单项不会阻止它被发布。

### 3. 预览与发布

运行 `npm run dev`，通关后点击“愿意” → “看看我们的照片墙”，检查图片、配文和放大预览。确认后重新运行 `npm run build`，发布新的 `dist/`。

> **隐私提醒：**公开仓库和公开网站中的图片可被他人下载，照片墙藏在结尾并不等于私密。上传前请征得照片中相关人员同意，并清除定位等 EXIF 信息；不要上传不希望公开的照片。
